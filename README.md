# 课文随身学 · 使用说明

一个纯前端（离线可用）的英语课文学习网页：内置《外研社五年级上册 Unit 3 · Happy together》完整讲解，
支持上传 txt / markdown / **PDF** 课文，自动提取词汇/短语/句式并生成全部题型习题。
手机浏览器打开即为底部导航 + 大按钮布局，电脑打开为经典顶部布局。

> 版本：v3（2026-10-23）。v1 备份在 `../unit3_v1_备份_2026-10-22/`。

## 🎬 情景剧场（v3 新增，打开即是首页）

用课本页面图当“舞台”，把课文内容放进画面里，以**对话**形式学习：

- **14 个场景**，每个场景取自课本对应页面的一块画面（Start up 故事 / Speed up 故事 / 韵律诗 / 听力 / 海报 / 国际友谊日…）
- 画面下方是**字幕条**：说话人头像 + 英文台词 + 中文翻译；人物用颜色区分（Duoduo 蓝、Tutu 橙、Bird 绿、Dog 棕、Rabbit 粉…）
- **▶ 连播**：自动逐句朗读并推进字幕，可暂停；⏮ ⏭ 手动切换；🔁 重听本句；点画面也能下一句
- 下方**对话气泡列表**像聊天记录，点任意一句就播放该句
- **🔍 取景**：可拖动 / 缩放 / 九宫格 / 候选轮换，自由「选取图片的某个部分场景」，选择会记住（存在浏览器本地）
- 🗺 全页、⛶ 放大观看（全屏）
- 课文页每块内容也配了对应页面图做淡背景

> 所有台词音频沿用逐句离线音频包，切换场景/连播都不会断。

## 打开方式

- 直接双击 `index.html`（Chrome / Edge 浏览器效果最佳），或
- 在本目录运行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`
- 手机上建议用同一局域网电脑起服务后访问，或把整个文件夹拷到手机用本地浏览器打开

## 发音说明（三级兜底 + 教材真人原声）

顶部可选「发音源」：

| 发音源 | 说明 |
| --- | --- |
| 自动（推荐） | 优先浏览器语音 → 失败自动用**离线音频包**（edge-tts 神经语音，覆盖本课 237 段文本）→ 再失败用在线发音 |
| 浏览器语音 | 系统自带 TTS（Windows/安卓通常可用；Linux 缺语音包时可能无声） |
| 离线音频包 | `audio/` 文件夹里的预生成语音，覆盖内置课文全部文本，100% 有声 |
| 在线发音 | 有道词典接口（需联网，任意课文可用） |

**教材真人音频**（`textbook_audio/`，来自淘知学堂教材全解）：

- 16 个课本词表单词的**真人朗读**会自动优先于合成音（听音选词题随机使用朗读/发音a 两版真声）
- 词汇卡上有「真人」徽章、🔈 中文释义按钮、📻 **词条原声**（真人朗读+例句）
- 课文页 4 个板块挂有 📻 **课本原声**：Start up 课文 / Speed up 故事 / Fuel up 歌谣 / Fuel up 听力
- 听力页有「课本原声」播放区；"听短文答题"的 Duoduo 篇、Sally & Mia 场景题直接使用原声

## 上传课文（txt / md / PDF）

- **文字层 PDF**：直接上传即可，自动提取文本并解析出全部习题。
- **扫描版 PDF**（课本扫描件大多是这种）：浏览器无法直接提取，应用会弹出提示，两种办法：
  1. 运行本目录的转换工具（本机已装好 OCR 依赖）：
     ```bash
     ./转换PDF课文.sh 你的课文.pdf        # 或 python3 tools/pdf2txt.py 你的课文.pdf
     ```
     生成同名 `.txt` 后再上传；
  2. 或复制课文文本，用「✏️ 粘贴文本」。
- 本目录已放好转换示例：`外研社五上_Unit_3_Happy_together.txt`（由你的 Unit 3 扫描版 PDF 转出，可直接上传体验）。

上传后自动：分句分段朗读、提取词汇表（未收录词可补中文意思）、匹配常用短语、识别 12 类句式、
生成语法选择/选词填空/连词成句/听句选句/听短文选句等习题。

## 文件结构

- `index.html` — 页面与样式（手机/电脑自适应）
- `data.js` — Unit 3 课堂数据 + 解析词典
- `app.js` — 学习/出题/发音兜底/间隔复习/上传解析逻辑
- `scenes/` — 课本 12 页页面图（压缩后共约 2.2MB，用于情景剧场取景）
- `audio/` — 预生成离线语音包 + `manifest.js` 清单（237 段）
- `textbook_audio/` — 教材配套真人音频（4 段课文原声 + 16 词 60 个分项音频）
- `pdfjs/` — 本地打包的 PDF.js（无需联网即可解析文字层 PDF）
- `tools/` — 语音再生成脚本与 `pdf2txt.py` OCR 转换工具
- `test.js` — Node 逻辑冒烟测试（`node test.js` 可重跑）
- `预览截图/` — 手机/电脑界面截图
- `外研社五上_Unit_3_Happy_together.txt` — 你的 PDF 转换结果（可直接上传体验）
